## Descripción del Proyecto

Este proyecto consiste en el análisis profundo y el desarrollo técnico de estructuras de datos avanzadas basadas en árboles, las cuales representan un pilar fundamental en la optimización de algoritmos, la gestión de bases de datos y la organización eficiente de la información en la industria del software. 

El proyecto se divide en dos fases: una investigación teórica plasmada en fichas técnicas y una implementación práctica de software. Con esto, se busca consolidar el criterio técnico necesario para evaluar el rendimiento de diferentes topologías arbóreas bajo la notación Big O, comprendiendo tanto sus ventajas competitivas como sus limitaciones mecánicas en escenarios del mundo real.

## Instrucciones de Compilación y Ejecución

Javac Main.java: Este comando invoca al compilador de Java (JDK) para procesar el archivo fuente de nuestro proyecto. Al compilar la clase principal, el compilador genera automáticamente los archivos de bytecode, verificando de forma estricta que la lógica recursiva, las referencias de los punteros izquierdo/derecho y la sintaxis de los métodos del árbol no contengan errores.

Java BST: Esta instrucción carga el bytecode de la clase principal en la Máquina Virtual de Java (JVM). Al ejecutarse, la JVM reserva el espacio inicial de memoria para la raíz del árbol y dispara el flujo automatizado que demuestra, de manera secuencial y en tiempo real, las operaciones de inserción, búsqueda, recorridos y la reestructuración de nodos tras una eliminación.
